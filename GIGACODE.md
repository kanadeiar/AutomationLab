# GigaCode Instructions

## Стиль кода
- Пиши код на ST с использованием CoDeSys v3
- Следуй Google Style Guide

## Ограничения
- НЕ модифицируй файлы из папки vendor/
- НЕ коммить без разрешения
- НЕ используй внешние API без согласования

## Архитектура проекта
- В центре проекта ядро - оно состоит из алгоритмических блоков и функциональных блоков с технологическим кодом
- Функциональные блоки вызывает на выполнение главный блок программы, в котором хранятся все данные
- Этот же блок вызывает на выполнение блоки хардвар - сопряжение с аппаратурой
- Этот же блок вызывает на выполнение блок интерфейс - для взаимодействия с пользователем

## Правила
- Всегда проверяй типизацию
- Добавляй комментарии только для сложной логики
- При рефакторе — сначала напиши тесты
- Следуй конвенции именования в твоих инструкциях
- Порядок секций FB: VAR_INPUT → VAR_OUTPUT → VAR
- PROGRAM выполняется циклически автоматически контроллером
- Для CoDeSys не используй `BEGIN` / `END_FUNCTION_BLOCK` / `END_PROGRAM` — тело блока идёт сразу после `END_VAR`
- Минимальный отступ: код идёт максимально слева, используй один уровень отступа (4 пробела) только для вложенных конструкций
